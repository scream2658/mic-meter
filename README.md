# 麦克风声强显示器（Mic Level Meter）

用 Python（tkinter + sounddevice + numpy）开发的 Windows 桌面悬浮音量表：实时显示麦克风输入声强（分贝 dB）。录音/录屏时对着麦克风说话，通过彩色蜂窝格动画直观判断自己的声音大小，方便调整嘴与麦克风的距离。

## 当前状态

- **版本**：v0.0.14（2026-08-14）
- 15 格蜂窝动画 + 分贝数值实时显示
- 深色面板 + 细边框、悬停显示关闭按钮、启动自动居中、始终置顶

## 功能

- **实时分贝（dB）显示**：数值随声音实时更新，颜色同步变化
- **15 格彩虹蜂窝**：底部红 → 绿 → 黄 → 顶部深蓝，饱和度渐变
- **深色面板背景 + 细边框**：与桌面内容明显区分，不刺眼
- **悬停关闭**：鼠标放到窗口上才显示右上角 ✕，点击即关闭（右键 / ESC 也可退出）
- **拖动与定位**：左键任意拖动位置，启动时自动居中，始终置顶
- **版本号常显**：窗口底部显示当前版本

## 界面说明

| 颜色 | 含义 |
|------|------|
| 红（底部少量） | 声音很小，录出来会很轻 |
| 绿 | 正常说话区间 |
| 黄 | 声音偏大 |
| 深蓝（顶部） | 峰值，接近爆音 |

正常录音建议说话时绿色区段常亮、黄色偶尔出现。如果长期只有底部红色亮起，说明麦克风增益太低，可到 Windows 麦克风设置里调高输入音量。

## 运行

```bash
python mic_meter.py
```

要求：Python 3.10+（自带 tkinter）；依赖 `numpy`、`sounddevice`。
